# Future Self 💌

A frontend project that lets users write a message
to their future selves as a digital time capsule.

## Current Version

Frontend only — built with:

- HTML5
- CSS3

## Planned Features

- JavaScript functionality
- User authentication
- Database
- Backend API
- Scheduled email delivery

## Future Idea

Write a message today.
Choose a date in the future.
Receive it when that day arrives. 💌
